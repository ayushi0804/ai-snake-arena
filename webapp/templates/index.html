Install & offline use

Use the Install button (Chrome/Edge) or: Android Chrome menu → Install app; iPhone Safari Share → Add to Home Screen. Installation needs HTTPS in production; http://localhost is allowed for development.

Works offline: the game itself (manual and AI), local high score, settings. Needs a connection: dashboard, history, leaderboard, benchmarks. Matches finished offline are saved on the device and uploaded when you reconnect.
